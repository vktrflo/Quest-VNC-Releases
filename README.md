# Quest VNC Server releases

Downloads for Quest VNC Server, the VNC server with sound for the Quest VNC headset app.
Get the newest version under [Releases](../../releases/latest):

- **Windows:** `QuestVncServer-<version>-windows.zip`. Unzip, double-click `QuestVncServer.exe`, and answer yes to install.
- **Linux (X11):** `QuestVncServer-<version>-linux.zip`. Unzip and run `./install.sh`.
- **macOS:** `QuestVncServer-<version>-macos.zip`. Unzip, then right-click `install.command` and choose Open.

Installed servers update themselves from this page. The other files in each release (`latest.json`, the bare
`.exe`, the Linux binary and the macOS `.tar.gz`) are what they download.
